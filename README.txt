САЙТ — краткая памятка
======================

ЗАПУСК
1. Запустите start.bat правой кнопкой -> "Запуск от имени администратора".
2. Разрешите доступ в брандмауэре Windows, если появится запрос.
3. Откройте в браузере: http://localhost (или http://IP-вашего-компьютера).

НАСТРОЙКИ (файл settings.json)
- siteTitle, siteDesc, contacts  — тексты сайта (можно менять и из админ-панели).
- port                           — порт сервера (менять в Блокноте, потом перезапуск).
- allowedIps                     — с каких IP можно регистрироваться. Пусто = со всех.
- adminIps                       — с каких IP регистрация даёт роль администратора.
  ВАЖНО: впишите свой IP сюда ДО первой регистрации. Свой IP виден в окне сервера.

ПЕРВАЯ РЕГИСТРАЦИЯ
- Зарегистрируйтесь с компьютера, чей IP указан в adminIps, — вы станете администратором.
- Все остальные регистрируются как пользователи.

РОЛИ
- user       — пользователь (чат, кабинет)
- local      — местный (пользователь + раздел "Игры")
- moderator  — модератор (пользователь + удаление сообщений + игры)
- admin      — администратор (всё + админ-панель)

ФАЙЛЫ
- users.json  — учётные записи (создаётся сам)
- chat.json   — история чата (создаётся сам)
- stats.json  — рейтинг игр (создаётся сам)
- img/hero.jpg — фон сайта; icon.jpg — иконка. Заменяйте своими или через админ-панель.
  При обновлении сайта из архива сохраните свои картинки заранее!

ОБНОВЛЕНИЕ САЙТА
Распакуйте новый архив в папку сайта с заменой файлов.
users.json, chat.json, stats.json и settings.json (если вы его правили) архив не трогает.
